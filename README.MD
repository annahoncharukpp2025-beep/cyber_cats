# Drone Flight Analyzer

Інтерактивний веб-застосунок для аналізу польотних логів ArduPilot DataFlash `.BIN`. Система автоматично розбирає бінарний лог, витягує GPS та IMU, обчислює ключові метрики польоту та показує результати у веб-інтерфейсі.

---

## Запуск проєкту

### 1. Перейдіть у папку проєкту

```bash
cd path/to/your/project
```

### 2. Створіть віртуальне середовище

#### Linux / macOS

```bash
python3 -m venv .venv
```

#### Windows

```bash
python -m venv .venv
```

### 3. Активуйте віртуальне середовище

#### Linux / macOS

```bash
source .venv/bin/activate
```

#### Windows

```bash
.venv\Scripts\activate
```

### 4. Встановіть залежності

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### 5. Запустіть застосунок

```bash
streamlit run app.py
```

### 6. Відкрийте браузер

Після запуску Streamlit покаже локальну адресу, зазвичай:

```text
http://localhost:8501
```

### 7. Завантажте `.BIN` файл

У відкритому інтерфейсі:
- натисніть **Upload ArduPilot .BIN**
- виберіть лог-файл
- дочекайтесь завершення обробки
- перегляньте метрики, графіки та 3D-траєкторію

## Що робить проєкт

Система виконує такі дії:

- читає ArduPilot DataFlash `.BIN` напряму
- витягує повідомлення **GPS**, **IMU**, **ATT**
- фільтрує невалідні GPS-точки
- визначає частоти семплювання GPS та IMU
- переводить координати з глобальної системи **WGS-84** у локальну систему **ENU**
- обчислює загальну дистанцію через **haversine**
- оцінює швидкість з IMU через **трапецієвидне інтегрування**
- відображає результати у вигляді метрик, графіків, таблиць та 3D-візуалізації

## Чому вибрано саме цей стек

Для цієї задачі потрібен був стек, який дозволяє швидко реалізувати повний робочий прототип: парсинг бінарних логів, чисельну обробку телеметрії, побудову графіків та створення веб-інтерфейсу. Python добре підходить для задач аналізу даних, `pymavlink` дає доступ до логів ArduPilot, а `Streamlit + Plotly` дозволяють швидко створити зручний інтерфейс для демонстрації результатів.

## Принцип роботи

### 1. Парсинг

Файл `.BIN` читається напряму через `pymavlink`, після чого з нього витягуються повідомлення:
- `GPS`
- `IMU`
- `ATT`

### 2. GPS

GPS-дані:
- очищаються від невалідних точок
- використовуються для обчислення дистанції, швидкості та висоти
- переводяться у локальні координати **ENU**

### 3. IMU

IMU-дані:
- беруться з полів прискорень по осях
- синхронізуються з даними орієнтації `ATT`
- переводяться з body frame у navigation frame
- компенсують гравітацію
- інтегруються методом трапецій для оцінки швидкості

### 4. Візуалізація

Після обробки результати відображаються у веб-інтерфейсі у вигляді:
- карток метрик
- графіків
- 3D-траєкторії
- таблиць GPS та IMU

## Обмеження

- інтегрування IMU без зовнішньої корекції накопичує похибку з часом
- точність результатів залежить від якості GPS-фіксів
- для повного аналізу бажано, щоб у лог-файлі були повідомлення `GPS`, `IMU`, `ATT`
